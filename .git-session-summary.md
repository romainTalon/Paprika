### 8. Décision technique importante: Services IA
**Problème**: cheerio + axios incompatibles avec React Native (dépendances Node.js)

**Solution**: Désactivation temporaire de l'export des services IA
- `RecipeImportService` ❌ (cheerio → node:stream)
- `NutritionService` ❌ (axios, dépendances lourdes)
- `ImageService` ❌ (axios)

**Plan futur**: Migration vers Supabase Edge Functions
- Edge Functions = environnement Deno (compatible cheerio)
- Sécurité: clés API côté serveur
- Performance: parsing HTML hors UI thread
